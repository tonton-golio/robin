# Label before filling

Synthetic pattern fixture.

## Observation

A blank tray is easier to label before it contains packets.

## Procedure

1. Write the category.
2. Attach the label.
3. Add one sample packet.
4. Check that the label remains visible.

> [!tip] Small experiment
> Try one tray first.
>
> - Adjust the position.
> - Repeat after the label is readable.

This is a fictional workflow, not evidence from a real project.
